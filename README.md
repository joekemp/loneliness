# No Drama

An open letter to my friend Holger about loneliness in Britain. It tries to state the problem rather than solve it: why a country rich in *belonging* has become poor in the more particular thing — *being known*. The claim is that the mechanism is a taboo on friction: a culture that treats disagreement as a failure of manners has removed the practice that turns acquaintance into intimacy. As such, I don't mind who reads it.

## Files

- **`letter_to_holger.md`** — the main document. A personal, argumentative letter, now titled *No Drama*. It states the problem and ends with three open questions for the reader. Start here.
- **`history.md`** — the historical scaffolding behind the letter's claim that reserve is made, not primordial: the eleven-link chain, with the load-bearing caveats, plus the full list of open questions. Kept out of the letter on purpose; read it with suspicion.
- **`references.md`** — the numbered works cited. The letter refers to sources by number only; this file holds the details.
- **`white_paper_skeleton.md`** — deprecated. This is where the project started: a planned white paper, with a twelve-chapter roadmap, per-chapter claims and counterarguments, and reading lists. It was superseded by the letter and is kept only as a record of the earlier thinking. Don't treat it as current.
- **`notes/`** — working notes. Rough, exploratory jottings on individual sources and themes (Arendt, Kate Fox, *Vereinskultur*, and others), gathered as the argument took shape. Not a coherent document and not part of the letter — just a paper trail for where particular ideas came from.

## Provenance

The letter is mine. Some of the prose was shaped with an AI, as its opening note says; the argument and any errors are mine.
